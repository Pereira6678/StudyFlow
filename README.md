# Projeto Mobile - Sprint 1

Estrutura inicial criada com Expo + React Native + TypeScript.

Comandos:

```bash
npm install
npm run start
```

Abra o Expo Go no celular e escaneie o QR code exibido em `expo start`.

Como testar a tela inicial:
- Inicie o projeto com `npm run start`.
- No Expo Go, abra o projeto via QR code.
- A tela inicial mostra nome, descrição, arquitetura e um botão "Testar funcionalidade" que exibe um alerta.
